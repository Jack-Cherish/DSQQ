# 大肥鱼一键包测试清单

先用 `python build/build.py` 打出 `dist/大肥鱼一键包.exe`，然后在干净的 Win10、Win11 机器上各跑一遍（没装过 Python、Node.js、QQ 的那种最好）。

每一项都写了「怎么做」和「应该看到什么」。看到的结果不一样，就把安装目录下的日志一起发回来。

| # | 怎么做 | 应该看到什么 |
|---|--------|--------------|
| 1 | 正常流程：双击 exe，按 6 页一路填完，用小号扫码 | 每页都能进下一步；装完之后大号私聊小号，她会回话；桌面上多了「启动大肥鱼」 |
| 2 | 安装进度走到一半时直接关掉窗口，再双击 exe | 从中断的那一步接着装，前面做完的步骤不重做，填过的 key 也不用再填 |
| 3 | 先占住 6185、6199、6099 这几个端口（比如 `python -m http.server 6185`），再安装 | 安装器自动改用别的空闲端口，照样装好；后台地址显示的是新端口 |
| 4 | 每种 key 都故意填错一次：QQ 号写字母、DeepSeek key 乱写、豆包的 APP ID 或 Token 填错、硅基流动 key 乱写 | 对应那一项显示「✗ 不对」，下面有一句中文说明怎么改；有错没改的时候「下一步」点不了 |
| 5 | 装好之后，在手机 QQ 上把小号的电脑登录踢掉，再双击「启动大肥鱼」 | 打开的是状态页，提示需要重新扫码，扫完能恢复正常 |
| 6 | 在后台改几项设置后，给机器人发 `/reset` | 对话记忆清空，改过的设置还在 |
| 7 | 开着 Windows Defender 或第三方杀毒软件安装 | 如果被拦了，有中文提示告诉用户怎么放行；放行后重新打开 exe 能接着装 |
| 8 | 安装路径选一个带中文或空格的目录，比如 `D:\我的 程序` | 页面提示换成纯英文路径，而且不让继续往下装 |
